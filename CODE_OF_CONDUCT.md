# Code de conduite

Ce projet réunit des personnes de pays, de langues et de métiers différents. Pour que la collaboration reste utile et agréable, nous attendons de chacun :

- **Du respect** : critiquer les idées et les données, pas les personnes.
- **De la rigueur bienveillante** : corriger une erreur en citant une source, sans ironie ni mépris.
- **De l'inclusion** : accueillir les contributeurs de toute origine, de tout niveau d'expérience, dans la langue du pays concerné ou en français ou en anglais.
- **De l'honnêteté** : signaler ce qui n'est pas vérifié plutôt que de le présenter comme un fait.

## Comportements inacceptables

Harcèlement, insultes, attaques personnelles, discrimination, publication d'informations privées d'autrui, et spam.

## Application

Les mainteneurs peuvent modifier, masquer ou supprimer les commentaires, issues et contributions qui ne respectent pas ce code, et bloquer temporairement ou définitivement un participant. Pour signaler un comportement, contactez le mainteneur du dépôt via son profil GitHub ([@aelharmouchi](https://github.com/aelharmouchi)).

Ce code s'inspire de l'esprit du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
